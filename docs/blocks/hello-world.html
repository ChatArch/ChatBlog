Hello World 知识块

这是 ChatBlog 的第一个知识块，用来说明公开内容应该如何写，以及这个站点为什么存在。

怎么写一篇公开内容​

  1. 先判断内容形态：是时间线文章，还是长期可复用的知识块。
  2. 时间线文章放在 blog/，长期知识块放在 docs/blocks/。
  3. 每篇内容都要写清楚 front matter，例如 title、date、tags、description。
  4. 内容必须适合公开：不要包含密钥、私有项目状态或内部进度记录。
  5. 不要直接公开原始聊天记录；应该先总结、整理、结构化，再发布。

ChatBlog 用来做什么​

ChatBlog 是公开知识产出层，适合放：

  • 从实现工作中沉淀出的技术笔记；
  • 架构解释和方案取舍；
  • 可公开分享的调试经验；
  • 比 Skill 更轻的知识块；
  • 和 ChatArch 项目相关的公开说明。

它的目标是让公开内容有稳定源码、有清晰结构，并且能被未来的人和 agent 反复引用。
